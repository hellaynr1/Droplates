# Droplates: rules for AI agents

Read this before changing anything. The owner is not a developer: explain in plain words and show results.

These rules are adopted from the owner's Investedia project (`hellaynr1/investedia`, its AGENTS.md) where they apply to a store.

## Owner's rules
1. **Never put anything live without the owner's "push" / "go".** Work on a branch, show screenshots at PC 1440px wide and phone 390px, and merge to `main` only when told.
2. If the owner mentions one device (PC or phone), change only that one and show the other before changing it.
3. Always check on phone width (390px).
4. Real content only. No fake reviews, prices, stock or sales numbers. Placeholders must be labeled as placeholders.
5. Design: black, dark-first, minimal, with generous whitespace, large clean type and few elements per screen. Keep motion subtle.
6. **Secrets:** never commit `.env`, API keys, payment keys or client secrets.
7. Never delete files, data, accounts or keys without asking.
8. **Label every option on the image itself.** When showing design options, print a clear label (A, B, C… plus a 2–3 word name) on each image, and use the same label in the message. Label before/after images "Now" / "New" and PC / phone.
9. A chosen design is finished only when every visible element of the mockup exists in the build. Missing data means stop and report, never ship a different design.

## Working style
- Small, focused changes; one commit per change with a clear message.
- Show screenshots, not descriptions.
- No money is taken and no prices are published until the company is registered.
- Explain what the owner must do themselves as numbered click-by-click steps.

## Voice
Professional, plain English, no cutesy copy. Name the product by its name, Droplates. Shopify is a trademark of Shopify Inc.; keep the disclaimer on the site.
