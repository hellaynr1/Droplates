Works where you build.

How installing a template will look on each platform.

Shopify

Upload the theme file to your store.

  1. In Shopify admin, go to Online Store → Themes.
  2. Choose Add theme → Upload zip file and select your Droplates theme.
  3. Click Customize to add your content, then Publish.

WordPress

Install it like any theme.

  1. In your dashboard, go to Appearance → Themes → Add New Theme.
  2. Click Upload Theme, choose your Droplates .zip and click Install Now.
  3. Click Activate, then customize it with your content.

HTML

Plain files you can host anywhere.

  1. Unzip the template and edit the content in any code editor.
  2. Upload the files to your host, such as GitHub Pages, Netlify or your own server.
  3. Connect your domain and you're live.
